# Portfolio 
Portfólio pessoal desenvolvido para apresentar minha trajetória como desenvolvedor, projetos, habilidades e conhecimentos em desenvolvimento web. O projeto também serve como espaço para aplicar na prática conceitos de HTML, CSS, JavaScript, responsividade e boas práticas de desenvolvimento.

Este projeto também proporcionou novos aprendizados, permitindo colocar conhecimentos em prática e aprimorar minhas habilidades.
